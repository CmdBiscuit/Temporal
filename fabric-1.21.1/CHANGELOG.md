## 1.0.0 (Fabric 1.21.1)

First release for Minecraft 1.21.1 on Fabric, with everything in Temporal 1.0.0 for NeoForge 1.21.1:

- Upscalers: DLSS, FSR 3, NIS, FSR 1
- Anti-aliasing: DLAA, FSR Native AA, TAA
- Frame generation: DLSS Frame Generation (2x-6x), FSR 3 Frame Generation (2x), with NVIDIA Reflex
- Dynamic resolution, an FPS counter that counts generated frames, hotkeys (F7 / F8)

Works with Sodium and Iris (with or without a shader pack). Needs Fabric API. With Mod Menu installed, its mod list has a settings button for Temporal; the pause menu has one either way.
